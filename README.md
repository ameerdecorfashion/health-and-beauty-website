# HBP. | Advanced Korean Skincare

A high-end, biological skincare ritual experience. This application is a production-ready ecommerce frontend built with React, Vite, and Tailwind CSS.

## 🌿 Philosophy
HBP (High Biological Performance) is at the intersection of biological science and ancient Seoul rituals. We specialize in "Glass Skin" protocols using high-potency ceramides and fermented yeast complexes.

## 🚀 Key Features
- **Ritual Discovery**: Immersive product gallery and detailed modals.
- **Dynamic Cart System**: Seamless context-based cart with real-time updates.
- **Secure Checkout**: Elegant, multi-step checkout flow.
- **Ritual Quiz**: Personalized skincare recommendations.
- **AI Specialist**: In-app AI chatbot for skincare consultations (Powered by Gemini).
- **Responsive Ritual**: Fully optimized for mobile, tablet, and desktop.
- **Artistic Design**: Custom "Artistic Border" aesthetic with luxury shadows and fluid typography.

## 🛠 Tech Stack
- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Routing**: React Router DOM v6
- **AI**: Gemini API

## 📦 Getting Started

### 1. Installation
```bash
npm install
```

### 2. Environment Setup
Create a `.env` file based on `.env.example`:
```env
VITE_GEMINI_API_KEY=your_gemini_key
```

### 3. Development
```bash
npm run dev
```

### 4. Build
```bash
npm run build
```

## 📐 Folder Structure
- `src/components`: Reusable UI sections and ritual blocks.
- `src/pages`: Main application routes (Home, Checkout).
- `src/context`: Global state management (Cart).
- `src/lib`: Utilities and helpers.
- `src/assets`: Static images and branding assets.
